# こいんのおみせ

3歳くらいのお子さん向けのお買い物ごっこです。1円・5円・10円・50円・100円・500円の硬貨をタップし、商品の値段と同じ金額をそろえます。「きく」ボタンで日本語の案内を読み上げます。読み上げは端末のブラウザに依存します。ゲーム内の商品価格は練習用です。

## 遊び方

1回のお買い物は30問です。商品と値段の組み合わせや出題順は、始めるたびに変わります。

`index.html` をブラウザで開きます。セットアップは不要です。公開後はスマホのブラウザで公開URLを開けます。

## GitHub Pages

リポジトリの既定ブランチにファイルをプッシュし、Settings → Pages で「Deploy from a branch」、既定ブランチ、`/(root)` を選んで保存します。公開が完了すると同じ画面にURLが表示されます。アプリはアカウント登録や個人情報の入力を求めず、プレイ内容も保存しません。

## 第2弾 オランダ語 タッチずかん

`dutch/index.html` をブラウザで開きます。絵をタッチするとオランダ語の単語を読み上げます。どうぶつ・たべもの・のりものを各6種類収録しています。読み上げは端末のブラウザに依存します。オランダ語の音声が見つからない場合は、端末の読み上げ設定でオランダ語の音声を追加してください。GitHub Pages では同じ公開URLの末尾に `dutch/` を付けて開けます。
