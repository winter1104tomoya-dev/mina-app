# こいんのおみせ

3歳くらいのお子さん向けのお買い物ごっこです。1円玉をタップして、1円・2円・3円の商品を順番に買います。「きく」ボタンで日本語の案内を読み上げます。読み上げは端末のブラウザに依存します。ゲーム内の商品価格はコインを数える練習用です。

## 遊び方

`index.html` をブラウザで開きます。セットアップは不要です。公開後はスマホのブラウザで公開URLを開けます。

## GitHub Pages

リポジトリの既定ブランチにファイルをプッシュし、Settings → Pages で「Deploy from a branch」、既定ブランチ、`/(root)` を選んで保存します。公開が完了すると同じ画面にURLが表示されます。アプリはアカウント登録や個人情報の入力を求めず、プレイ内容も保存しません。
